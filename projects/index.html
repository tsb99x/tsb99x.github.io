Access Log Tabulator #

Примитивный, но быстрый преобразователь (табулятор) журналов доступа HTTP-сервера из формата Apache Combined Log в формат Tab-Separated Values. Это позволяет элементарно импортировать данные как таблицу в БД. Программа также переводит даты из формата 10/Oct/2000:13:55:36 -0700 в более привычный, похожий на ISO 8601: 2000-10-10T13:55:36-0700.

UTF8 Range Checker #

Простой "проверятор" того, все ли Unicode символы в тексте входят в указанные интервалы. Основной сценарий использования для меня – проверка страниц этого сайта на набор символов, которые я указываю в unicode-range у font-face. Утилита бывает полезна, чтобы просто посмотреть на коды символов в тексте.

Glider #

Веб-версия Game of Life. Простой вариант алгоритма без излишков. Хорошо подходит для тестирования эффективности JIT компилятора у движка JavaScript. Ещё один вариант – проверка скорости рендеринга Canvas. Это старый, архивный проект. Оригинал был сделан в июле 2017 года.
