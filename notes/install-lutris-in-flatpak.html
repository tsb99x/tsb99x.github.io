Команды

Установить Flatpak:

$ sudo apt install flatpak

Установить плагин для Discover в KDE, чтобы получать обновления пакетов Flatpak:

$ sudo apt install plasma-discover-backend-flatpak

Добавить Flathub как репозиторий Flatpak:

$ flatpak remote-add --if-not-exists \
    flathub https://dl.flathub.org/repo/flathub.flatpakrepo

Установить Lutris как Flatpak:

$ flatpak install flathub net.lutris.Lutris

Транскрипт видео

Введение

Lutris – это удобный инструмент для Linux. Он позволяет объединить в одной библиотеке игры для Windows, PSP, Xbox, PlayStation и других платформ.

В этом видео рассмотрим один из вариантов как можно установить Lutris.

Процесс установки я покажу на виртуальной машине с Debian 12. Это чистый Live DVD с KDE, на котором я установил тёмную тему, сменил обои и скрыл панель задач. Ничего более.

Где инструкции

Для начала откроем сайт Lutris (это lutris.net) и перейдем в раздел Download. Здесь можно найти инструкции по установке для разных дистрибутивов Linux. Мы воспользуемся универсальным способом – пакетом Flatpak. Переходим по ссылке на Flathub – это самое большое хранилище пакетов Flatpak.

На странице Lutris на Flathub есть большая синяя кнопка Install. Чтобы упростить установку, рекомендую нажать на стрелку справа от этой кнопки – тогда Flathub покажет команды для ручной установки. Там же есть ссылка на setup guide с инструкциями по установке бэкенда Flatpak. Открываем эту ссылку в новой вкладке.

Здесь представлено много дистрибутивов Linux. Инструкции для каждого будут отличаться. Нам нужны инструкции для Debian, открываем их.

Установка Flakpak

Первый шаг – установка бэкенда Flatpak в систему. Скопируем команду, открываем Konsole, вставляем команду и нажимаем Enter для выполнения. Подтверждаем установку, снова нажав Enter.

Установка завершена, переходим к следующему шагу. Теперь установим плагин для магазина приложений Discover, чтобы обновления пакетов Flatpak отображались вместе с системными. Скопируем команду, вставим её в Konsole и нажимаем Enter для запуска. Подтверждаем установку, снова нажав Enter.

Отлично, установка прошла успешно. Последний шаг – добавление хранилища Flathub в качестве источника пакетов для Flatpak. Повторяем процедуру. Копируем команду, вставляем её в Konsole и нажимаем Enter.

Flatpak просит перелогиниться, чтобы новые программы из установленных пакетов появлялись в списке приложений. Мы сделаем это позже, а сейчас установим Lutris.

Установка Lutris

Закрываем эту инструкцию и копируем команду ручной установки пакета со страницы Lutris. Вставляем её в Konsole и нажимаем Enter. Подтверждаем установку из Flathub со списком зависимостей, ещё раз нажав Enter.

У Lutris есть много зависимостей. В основном – это библиотеки, необходимые для запуска игр. Версии таких библиотек для Flatpak бывают значительно новее, чем у моего Debian. Именно поэтому я и рекомендую использовать версию Lutris в виде Flatpak. Для некоторых игр наличие свежих библиотек может быть критически важно для запуска.

Установка завершена. Чтобы Lutris появился в списке программ, необходимо выйти из системы и снова войти.

Первый запуск Lutris

После повторного входа в систему сразу запускаем Lutris. В левом углу окна можно увидеть, что Lutris автоматически начал загружать необходимые зависимости. Теперь необходимо дождаться завершения их загрузки.

Зависимости загружены, и Lutris готов к работе. На этом всё, спасибо Вам за внимание!
