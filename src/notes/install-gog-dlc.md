## Транскрипт видео

### Установить как игру?

В прошлом видео мы установили Deus Ex в Lutris из оффлайн-установщика GOG.
Сегодня установим дополнение Revision, которое тоже распространяется как
отдельный установщик, и разберем возможные проблемы по пути.

У меня уже загружены две части оффлайн-установщика для Revision. Обратите
внимание: нужно скачать все части и перед установкой сложить их в одну папку.

Первая мысль, которая приходит в голову -- попробовать установить Revision как
отдельную игру. На lutris.net как раз есть запись для Deus Ex: Revision.
Давайте посмотрим, сработает ли это!

Открываем Lutris. Выбираем "Install a Windows Game", вводим название "Deus Ex:
Revision", нажимаем "Install", выбираем "Install" для Setup File, оставляем
путь нового префикса по умолчанию, выбираем установщик иии...

Видим сообщение, что базовая игра не была установлена. Закрываем установщик.
Журнал исполнения показывает ошибку, и это нормально, Lutris так понимает, что
установка провалилась, нажимаем "Abort". Lutris предложит удалить все файлы,
которые уже были созданы для Revision. Соглашаемся с удалением файлов, ведь
префикс "Games/deus-ex-revision" нам теперь не нужен.

### Запуск EXE в префиксе

Что же делать? Нам нужно установить Revision в то же окружение, в тот же Wine
prefix, где и установлен Deus Ex. В Lutris для этого есть отличная функция
запуска EXE в префиксе, которая нам и поможет. Нажимаем "Run EXE inside Wine
prefix", и выбираем файл установщика Revision.

Отлично! Теперь установщик запустился без ошибок, значит, все работает как и
надо. Соглашаемся с условиями использования и нажимаем "Install". Важно:
выходим из установщика, не запуская игру.

Ух, ну давайте запускать Revision. Эх... Хех... Это не Revision. Заставка
старая, меню старое, графика старая. Можно попробовать запустить новую игру,
конечно. Да нет, это обычный Deus Ex. Окей, выходим из игры.

### Где нужный LNK?

Чтобы разобраться, что пошло не так, нужно посмотреть на конфигурацию для Deus
Ex. Открываем "Configure" и переходим на вкладку "Game Options". Здесь есть
поле Executable, т.е. исполняемый файл. Там сейчас указан "Launch Deus Ex
GOTY.lnk".

Можно подумать, что в поле Executable будет EXE файл. Интересный факт:
большинство программ в Windows запускаются не напрямую через EXE файлы, а через
специальные ссылки, которые содержат параметры запуска. Эти ссылки имеют
расширение LNK. Давайте откроем файловый менеджер, нажав на кнопку с папкой.

Вот тот самый LNK. При установке игры, оффлайн установщик создаёт в папке ровно
один LNK файл для запуска игры. После установки Lutris автоматически находит
этот LNK и записывает его в конфигурацию как Executable.

Возникает вопрос: а где найти LNK файл для Revision? К сожалению,
универсального ответа для любой игры нет. Но мы можем найти все LNK файлы
внутри Wine префикса и выбрать из них подходящий.

Открываем префикс "Games/deus-ex", а затем открываем "drive_c" в терминале.
Теперь используем команду "find . -type f -iname '*.lnk'". Эта команда
расшифровывается как: найти в этой папке все файлы, где имя файла заканчивается
на .lnk.

Посмотрите, здесь несколько ссылок. Первая, в папке "Desktop", -- это ярлык,
который Вы бы увидели на Рабочем Столе в Windows. Следующие семь ссылок
находятся в папке "Start Menu" -- это те самые ярлыки, что в меню Пуск на
Windows. А последняя ссылка -- это текущая конфигурация игры, обычная Deus Ex.

Находим ссылку с Revision в названии, вот она! Проходим в ProgramData,
Microsoft, Windows, Start Menu, Programs, Deus Ex GOTY \[GOG.com]. Скопируем
путь файла "Deus Ex Revision.lnk". Теперь сбрасываем значение поля Executable с
помощью стрелки справа от поля и вставляем путь найденной ссылки для Revision.
Сохраняем конфигурацию, нажав на Save и запускаем игру.

### Запуск Revision

Вот, видим окно предварительной конфигурации для Revision. Настраиваем по вкусу
и запускаем. В игре сразу настрою чувствительность мыши чуть-чуть пониже.
Запустим тренировку. Текстуры уже видно другие. Проверим основную игру. Ага,
это точно Revision, карта другая, вон, сарайчик стоит.

Ну что, Revision запустился, на этом всё! Спасибо Вам за внимание!
